# Zelda: A Link to the Past — transcriptions sources

Fichiers MIDI de fans utilisés par `scripts/deux-mondes.mjs`, conservés tels quels (octet pour octet) pour que le
projet reste reproductible même si le site d'origine disparaît. Musique : Koji Kondo (Nintendo, 1991).
Téléchargés sur https://www.vgmusic.com/music/console/nintendo/snes/ et choisis parce que des transcriptions
indépendantes y retrouvent les mêmes notes (part des notes d'un fichier retrouvées dans les autres, au même temps
et à la même hauteur). Les fichiers « Conversion » du site (extraits du jeu) n'ont pas servi : leur timing n'est
pas calé sur les temps.

| Fichier | Thème | Transcription | Accord avec les autres |
|---------|-------|---------------|------------------------|
| `Zelda3_Story_Theme.mid` | Prologue | Haakon Marthinsen | 88-100 % |
| `Zelda3_Light_World_Theme.mid` | Light World | Haakon Marthinsen | 91-99 % |
| `Zelda3_Fairy_Theme.mid` | Fontaine des fées | Haakon Marthinsen | 77-86 % |
| `Zelda3_Lost_Woods_Theme.mid` | Lost Woods | Haakon Marthinsen | 75-78 % |
| `The_Dark_World_No_Quicktime.mid` | Dark World | Ryan Pruitt | 87-97 % |
| `z3ganonbat.mid` | Combat contre Ganon | Mark Jansen | 84 % |
| `z3credit.mid` | Générique | anonyme | 90-100 % (noyau commun à 3 transcriptions) |

Écartés faute d'accord suffisant entre transcriptions : pluie, sanctuaire, Triforce, épilogue.
