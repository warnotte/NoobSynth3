# Super Mario World — transcriptions sources

Fichiers MIDI de fans utilisés par `scripts/reve-dinosaur.mjs`, conservés tels quels (octet pour octet) pour que
le projet reste reproductible même si le site d'origine disparaît. Musique : Koji Kondo (Nintendo, 1990).
Téléchargés sur https://www.vgmusic.com/music/console/nintendo/snes/ et choisis parce que des transcriptions
indépendantes y retrouvent les mêmes notes (accord note à note).

| Fichier | Thème | Transcription | Accord avec les autres |
|---------|-------|---------------|------------------------|
| `SMW-Star_Road.mid` | Star Road | Frederico Saar | 96-100 % |
| `SMWWorldMap.mid` | Carte de Donut Plains | Daniel Lippert | 99-100 % |
| `SMWForestOfIllusion.mid` | Forest of Illusion | Daniel Lippert | 65-97 % |
| `smwcstle.mid` | Château | Erik | 85-96 % |
| `Smwend.mid` | Générique de fin | Tim Connolly | 81-88 % (1re minute 26) |

Overworld (SevenChaos) et Athletic (AI Musicware Branch, piste « Yoshi » retirée) sont dans `public/midi-presets/`.
